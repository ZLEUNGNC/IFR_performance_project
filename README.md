Run main.py and enter the lap number youd like to analyse.

Use the mouse to click on any data point you want, the track, the G-G graph, the lateral G vs speed scatter, the speed vs distance graphs, any one.

Every graph syncs with every other graph so you can cross reference them.

Scroll down the right to see more graphs.

There are windows for every graph showing the value at the point.
